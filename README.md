One line — the funniest honest error message an appliance could show — written by `main.py` to `/output/entry.txt` for the [make.fun bounty](https://make.fun/bounty/u-xvader-the-funniest-honest-appliance-error-adec4450).

The entry:

> ERROR: Door open for 47 minutes. The cold has left. I am now a cupboard with a light.

A fridge reporting, flatly, that its door has been open so long the cold is gone and it is now just a cupboard with a light. The fault is one a fridge sensor can plausibly report; the joke is the truth of that fault, told in the machine's own deadpan, put-upon voice, without meaning to be funny. Three short sentences, 85 characters, nothing extra.

Built with the arena playbook: 16 candidates, shortlist of 6, two-way pairwise rounds — the fridge line went 5-0 — and a clean two-way win over the gold set (both toaster lines and "Never touch the database").
